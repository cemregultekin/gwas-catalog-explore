
# 🧬 GWAS Catalog Explorer

An interactive web application designed to filter, explore, and visualize datasets from the [NHGRI-EBI GWAS Catalog](https://www.ebi.ac.uk/gwas/). 

This tool is built specifically for bioinformatics researchers focusing on **Polygenic Risk Scores (PRS)** and **cross-ancestry portability studies**, allowing for rapid literature screening and data acquisition without needing to write complex scripts.

## ✨ Key Features
* **Live Data Fetching:** Automatically fetches the most up-to-date study inventory directly from EBI servers.
* **Advanced Filtering:** Precisely filter studies by Disease/Trait, Ancestry/Population, Publication Year, and the availability of Full Summary Statistics.
* **Interactive Visualizations:** * Analyze Sample Size (N) distribution across diverse global populations.
  * Track publication trends over time for specific traits.
* **Instant Export:** Download your custom-filtered dataset as a clean CSV file ready for downstream analysis.

## 🛠️ Tech Stack
* **Framework:** [Streamlit](https://streamlit.io/)
* **Data Manipulation:** Pandas
* **Data Visualization:** Plotly Express
